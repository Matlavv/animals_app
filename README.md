# Projet Firebase avec React Native et Expo

Ce projet est une application mobile développée avec React Native et Expo, utilisant Firebase comme backend.

## Installation

1. Clonez ce dépôt sur votre machine locale.
2. Assurez-vous d'avoir Node.js installé sur votre machine.
3. Exécutez la commande `yarn install` pour installer les dépendances du projet.
4. Créez un projet Firebase sur le site officiel de Firebase.
5. Copiez les informations de configuration Firebase dans le fichier `firebaseConfig.js`.
6. Exécutez la commande `expo start` pour lancer l'application.

## Fonctionnalités

- Authentification utilisateur avec Firebase Authentication.
- Stockage de données avec Firebase Realtime Database.
- Stockage de fichiers avec Firebase Storage.

## Structure du projet

- Le répertoire `screens` contient les différentes vues de l'application.
- Le répertoire `components` contient les composants réutilisables.
